# Crease
An open-source, live cricket score-viewing and scoring platform.

## Key Features
- Live ball-by-ball updates
- Full scorecard breakdowns
- Team profiles and statistics
- Fixtures and results
- League tables

## Tech Stack

### Backend
- Python / Flask
- SQL

### Frontend

- HTML
- CSS
- JS

## Contributing
Feel free to open a pull request if you want to improve Crease as the project develops.
