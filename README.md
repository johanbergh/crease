# Crease
**A modern, open-source live cricket scoring and score-viewing platform.**

---

## Features

### Live Matches

- Live match scores
- Ball-by-ball updates
- Full scorecard breakdowns

### Fixtures

- Upcoming matches
- Match dates and times
- Match status

### Teams

- Team profiles
- Team statistics
- Fixtures and results
- Squad information
- Team hierarchy

Example:

```text
South Africa
├── South Africa A
├── South Africa U19
└── South Africa Schools
```

### Players

- Player profiles
- Recent performances
- Career statistics

### Statistics

- League tables
- Performance records

### Accounts

- Follow teams
- Follow players
- Follow competitions

---

## Project Status

The Crease project is currently **under active development**.

The project is being developed incrementally, starting with the frontend and core application structure before expanding into the complete scoring and data system.
